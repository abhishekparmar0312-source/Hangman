# Hangman Game 🎮

A simple command-line Hangman game written in Python. A random word is chosen, and you have 6 lives to guess it one letter at a time.

## Features
- Random word selection from a built-in word list
- Lives counter shown with hearts ❤️
- Shows the letters you have already guessed
- Input validation (rejects numbers, multiple letters, and repeated guesses)
- Play again option after each round

## How to run
```
python hangman.py
```

## How to play
1. A random word is hidden and shown as blanks (`_ _ _ _`).
2. Type one letter at a time.
3. A correct letter is revealed in the word.
4. A wrong letter costs you one life.
5. Guess the whole word before you run out of lives to win!

## Concepts used
- Functions
- Sets and loops
- String methods
- Input validation
